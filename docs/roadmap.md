# Roadmap

## v1 (0.1.x - 0.9.x; version components never reach two digits — roll up instead)
1. Matter workspaces: open a folder or file, recent matters, Linux and Windows.
2. DOCX editing via ONLYOFFICE / LibreOffice handoff, in-app notes, PDF view,
   annotate, Bates stamp, true redaction.
3. Ask over the matter, local by default, with page and span citations; AI
   redlines as real track changes.
4. Playbook review and a clause library (NDA, MSA, employment samples).
5. Citation checker and Bluebook formatter (eyecite + CourtListener) with a
   Verify-All gate before export.
6. Deadline extraction and calendar export, with the rule and arithmetic shown.
7. Synthetic demo matter, `legal doctor`, privacy tier UI, per-matter AI log.

**Explicit non-goals for v1:** filing anything, sending or signing without a
human approving that specific action, trust accounting, Relativity-scale
e-discovery, Westlaw or Lexis content, mobile, macOS.

## Later
P1 connectors (Clio, DocuSign, PACER), local transcription and deposition prep,
document automation interviews, small-matter e-discovery, due diligence as a
batch skill over a folder.
